คู่มือผู้ดูแลระบบ TapTime

ระบบลงเวลาเข้า-ออกงานด้วย GPS · เวอร์ชัน 1.3 (สิงหาคม 2569)

คู่มือนี้เขียนสำหรับเจ้าของธุรกิจและฝ่ายบุคคล ไม่ต้องมีพื้นฐานด้านเทคนิค แต่ละหัวข้อจะบอกทั้ง วิธีทำ และ ควรตั้งค่าอย่างไรจึงเหมาะกับธุรกิจ ส่วนคู่มือของพนักงานอยู่คนละไฟล์ (manual-employee.html) ส่งให้พนักงานอ่านได้เลย

1. ระบบนี้ทำอะไรได้บ้าง

TapTime คือระบบลงเวลาทำงานที่ใช้ ตำแหน่ง GPS และ ลายนิ้วมือ/ใบหน้าของพนักงานเอง ยืนยันว่าคนที่กดเช็คอินคือเจ้าตัวจริง และอยู่ที่หน้างานจริง

สิ่งที่ระบบยังทำไม่ได้ (ตั้งใจไม่ทำในเวอร์ชันนี้)
  • ไม่คำนวณเงิน — ระบบเก็บ "จำนวนชั่วโมง" ให้เท่านั้น แล้วส่งต่อให้ระบบเงินเดือนของคุณคิดเอง
  • ไม่รองรับกะกลางคืนหรือกะข้ามเที่ยงคืน — งานที่เริ่มก่อนเที่ยงคืนแล้วเลิกหลังเที่ยงคืน ระบบจะคำนวณให้ไม่ได้ ต้องให้แอดมินบันทึกเอง (ดู ปัญหาที่พบบ่อย)
  • นโยบาย OT มีชุดเดียวใช้ทั้งบริษัท — ยังตั้งกฎแยกรายสาขาหรือรายบุคคลไม่ได้

2. เริ่มใช้งานครั้งแรก

เข้าสู่ระบบ

ทุกคนเข้าที่หน้าเดียวกันคือ /login ระบบแยกให้เองว่าจะพาไปหน้าไหน

คุณเป็นเปิดจากระบบพาไป
ผู้ดูแลระบบคอมพิวเตอร์ / โน้ตบุ๊กหน้าจัดการของผู้ดูแล
ผู้ดูแลระบบมือถือ / แท็บเล็ตหน้าพนักงาน (เพราะแอดมินก็ต้องลงเวลาเหมือนกัน)
พนักงานอะไรก็ได้หน้าพนักงาน
ถ้าเป็นแอดมินแล้วอยากเข้าหน้าจัดการจากมือถือ พิมพ์ /admin ต่อท้ายชื่อเว็บโดยตรงได้ แต่หน้าจัดการออกแบบมาสำหรับจอใหญ่ ใช้บนมือถือจะอึดอัดมาก แนะนำให้ใช้คอมพิวเตอร์

ช่อง "จดจำฉันไว้" — ติ๊กแล้วจะไม่ต้องล็อกอินใหม่นาน 30 วัน ถ้าไม่ติ๊ก ระบบจะให้ล็อกอินใหม่เมื่อปิดเบราว์เซอร์ หรืออย่างช้าภายใน 12 ชั่วโมง

อย่าติ๊ก "จดจำฉันไว้" บนเครื่องที่ใช้ร่วมกัน เช่นคอมพิวเตอร์กลางในออฟฟิศ หรือแท็บเล็ตหน้าร้าน เพราะคนถัดไปจะเข้าใช้สิทธิ์คุณได้ทันที

ลำดับการตั้งค่าที่แนะนำ

ตั้งตามลำดับนี้จะราบรื่นที่สุด เพราะแต่ละข้อใช้ค่าจากข้อก่อนหน้า

  1. ธุรกิจ / สาขา / ตำแหน่ง — ปักหมุดพิกัดที่ทำงาน ตั้งเวลาเข้า-ออก และเกณฑ์มาสาย ต้องทำก่อน เพราะถ้าไม่มีพิกัด พนักงานจะเช็คอินไม่ได้เลย
  2. วันหยุด — ใส่วันหยุดประจำสัปดาห์ และวันหยุดราชการของปีนี้
  3. ตั้งค่าวันลา — สร้างประเภทการลา กำหนดโควตา และเลือกว่าใครได้สิทธิ์อะไร
  4. ตั้งค่า OT — เลือกโหมดและกฎการนับ (ถ้าบริษัทไม่มี OT ให้เลือกโหมด "ปิดระบบ OT")
  5. จัดการพนักงาน — เพิ่มพนักงานพร้อมอีเมล ระบบจะส่งลิงก์ให้ตั้งรหัสผ่านเอง
  6. ทดลองใช้จริง 1 วัน — ให้พนักงาน 2–3 คนลองเช็คอิน–เช็คเอาท์ แล้วดูรายงานรายวันว่าตัวเลขถูกต้อง

3. ตั้งค่าธุรกิจ สาขา และเวลา

เมนู ธุรกิจ / สาขา / ตำแหน่ง

พิกัดและรัศมีเช็คอิน

เลื่อนแผนที่แล้วคลิกจุดที่ต้องการ หรือลากหมุดไปวาง วงกลมสีฟ้าคือ รัศมีที่ยอมให้เช็คอินได้ พนักงานที่อยู่นอกวงนี้จะกดเช็คอินไม่ผ่าน

ลักษณะสถานที่รัศมีที่แนะนำเหตุผล
ร้านค้า / ออฟฟิศเล็ก50 เมตรแน่นพอที่จะกันคนเช็คอินจากบ้านข้าง ๆ
อาคารสำนักงาน80–120 เมตรGPS ในตัวอาคารคลาดเคลื่อนง่าย ต้องเผื่อ
โรงงาน / คลังสินค้า150–300 เมตรพื้นที่กว้าง จุดเข้างานอาจไกลจากหมุด
ตั้งรัศมีแคบเกินไปจะเจอปัญหาทันที GPS บนมือถือคลาดเคลื่อนได้ 10–50 เมตรเป็นเรื่องปกติ โดยเฉพาะในอาคารหรือวันฝนตก ถ้าตั้ง 20 เมตรจะมีพนักงานเช็คอินไม่ผ่านทุกวันจนต้องโทรหาคุณ เริ่มที่ 50 เมตรก่อน แล้วค่อยปรับลงถ้าไม่มีปัญหา

ระบบยังปฏิเสธพิกัดที่ ความคลาดเคลื่อนเกิน 200 เมตร ด้วย เพราะค่าแบบนั้นมักไม่ได้มาจาก GPS จริงแต่มาจากการเดาตำแหน่งผ่านเครือข่าย ซึ่งปลอมได้ง่าย

เวลาทำงานและเวลาพัก

ช่องความหมายและผลที่เกิดขึ้น
เวลาเริ่มงาน ใช้เป็นจุดตั้งต้นคำนวณ "มาสาย" และเป็นเส้นแบ่งของ OT ก่อนเข้างาน
เวลาเลิกงาน ใช้เป็นเส้นแบ่งของ OT หลังเลิกงาน ตั้งผิดคือ OT ผิดทั้งบริษัท
ชั่วโมงพัก/วัน จำนวนชั่วโมงที่หักออกจากเวลาทำงาน เช่น พักเที่ยง 1 ชั่วโมง
หักเวลาพักเมื่อทำงานถึง ทำงานไม่ถึงจำนวนชั่วโมงนี้ จะไม่ถูกหักเวลาพัก
ใส่ 0 = หักทุกกรณี (ไม่แนะนำ)
เกณฑ์การมาสาย (นาที) มาช้าไม่เกินกี่นาทีจึงยังนับว่าปกติ เช่นตั้ง 15 แล้วเข้างาน 08:10 จะยังเป็น "ปกติ" แต่ระบบยังบันทึกไว้ว่าสาย 10 นาที
เช็คอินก่อนเวลาได้ (นาที) กำหนดกรอบเวลาเช็คอิน — เช็คอินได้เร็วที่สุดคือ "เวลาเริ่มงาน − ค่านี้"
ตั้ง 30 แล้วเวลาเริ่มงาน 08:00 → พนักงานกดเช็คอินได้ตั้งแต่ 07:30 ก่อนหน้านั้นปุ่มเป็นสีเทากดไม่ได้ และจะปลดล็อกให้เองเมื่อถึงเวลา
เว้นว่าง = ไม่จำกัด (เช็คอินได้ตั้งแต่เที่ยงคืน)

กรอบเวลาเช็คอิน — สิ่งที่คนถามบ่อยที่สุด

"ปิดระบบ OT แล้วทำไมพนักงานยังเช็คอินตอนตีสองได้" — เพราะเป็นคนละเรื่องกัน

การตั้งค่าควบคุมอะไร
โหมด OT ควบคุมว่า เวลาที่อยู่เกินจะถูกนับเป็น OT หรือไม่ — ไม่ได้ห้ามลงเวลา
เช็คอินก่อนเวลาได้ (นาที) ควบคุมว่า เช็คอินได้ตั้งแต่กี่โมง — นี่คือตัวที่ใช้ห้ามลงเวลานอกกรอบ
ถ้าไม่อยากให้เช็คอินนอกเวลางาน ให้ตั้งที่ช่อง "เช็คอินก่อนเวลาได้" ไม่ใช่ปิดระบบ OT — ปิด OT แล้วพนักงานยังลงเวลาได้เหมือนเดิม แค่ไม่ได้ OT
ข้อยกเว้นเดียว ถ้าเปิด "นับ OT ก่อนเวลาเข้างาน" ในหน้าตั้งค่า OT ไว้ กรอบเวลานี้จะถูกยกเลิกโดยอัตโนมัติ เพราะขัดกันเอง — คุณบอกว่าอยากให้มาทำงานก่อนเวลาได้ แต่อีกฝั่งบอกว่าห้ามเช็คอินก่อนเวลา
เรื่องที่ตั้งใจไม่ทำ: ไม่บล็อกการเช็คเอาท์ เพราะถ้าห้ามเช็คเอาท์หลังเวลาเลิกงาน คนที่ติดงานจนดึกจะเช็คเอาท์ไม่ได้เลย กลายเป็นรายการค้างที่ต้องมาตามแก้ทีหลัง — ปล่อยให้เช็คเอาท์ได้เสมอปลอดภัยกว่า ส่วนเวลาที่เกินจะถูกนับหรือไม่ ให้ไปคุมที่นโยบาย OT แทน
ทำไมต้องมีช่อง "หักเวลาพักเมื่อทำงานถึง" ถ้าหักเวลาพักทุกกรณี พนักงานที่มาทำครึ่งวัน 3 ชั่วโมงจะถูกหักไป 1 ชั่วโมงทั้งที่ยังไม่ได้พัก เหลือแค่ 2 ชั่วโมง ตั้งค่านี้เป็น 6 ชั่วโมง จะสมเหตุสมผลกับกะทำงานทั่วไป

4. จัดการพนักงาน

เพิ่มพนักงาน + อีเมลเชิญ

  1. กดปุ่ม เพิ่มพนักงาน แล้วกรอกข้อมูล — ช่องที่มีเครื่องหมาย * ต้องกรอก
  2. ใส่อีเมลของพนักงานด้วย ระบบจะส่งลิงก์ไปให้เขาตั้งรหัสผ่านเอง ถ้าไม่ใส่อีเมล พนักงานคนนั้นจะเข้าระบบไม่ได้
  3. อัปโหลดรูปได้ ระบบย่อให้เป็น 150×150 พิกเซลอัตโนมัติ ไม่ต้องย่อมาก่อน
  4. กดบันทึก — พนักงานจะได้อีเมล กดลิงก์ ตั้งรหัสผ่าน แล้วเข้าใช้ได้ทันที

ปุ่มจัดการในตารางเป็นไอคอน เอาเมาส์ไปวางจะขึ้นข้อความบอกว่าคืออะไร

ปุ่มใช้เมื่อไร
แก้ไขเปลี่ยนข้อมูล เปลี่ยนสาขา เปลี่ยนสถานะเป็นลาออก
ส่งอีเมลเชิญใหม่พนักงานบอกว่าไม่ได้รับอีเมล หรือลิงก์หมดอายุแล้ว
ตั้งรหัสผ่านให้พนักงานลืมรหัสผ่านและเข้าอีเมลไม่ได้ — คุณตั้งให้แล้วบอกเขาด้วยวาจา
อุปกรณ์ / passkeyดูว่าเขาผูกเครื่องอะไรไว้ ถอนสิทธิ์เครื่องที่หายหรือเปลี่ยนเครื่อง
ให้สิทธิ์ผู้ดูแลเลื่อนพนักงานเป็นแอดมิน หรือถอนสิทธิ์คืน
ลบลบถาวร ข้อมูลลงเวลาทั้งหมดของคนนั้นจะหายไปด้วย
อย่ากดลบพนักงานที่ลาออก ให้ แก้ไข → เปลี่ยนสถานะเป็น "ลาออก" แทน เขาจะเข้าระบบไม่ได้และหายจากรายงาน แต่ประวัติการทำงานยังอยู่ครบ ซึ่งจำเป็นตอนตรวจสอบย้อนหลังหรือคำนวณค่าจ้างงวดสุดท้าย

ให้สิทธิ์ผู้ดูแลระบบ

กดไอคอนรูปโล่ในแถวของพนักงานคนนั้น คนที่เป็นแอดมินจะมีเครื่องหมายโล่กำกับในตาราง

สิทธิ์แอดมินมีผลทันที ทั้งตอนให้และตอนถอน ไม่ต้องให้เขาออกจากระบบแล้วเข้าใหม่ และถ้าคุณถอนสิทธิ์ เขาจะถูกตัดออกจากหน้าจัดการทันที แม้กำลังเปิดค้างอยู่ก็ตาม

ควรมีแอดมินอย่างน้อย 2 คน เผื่อกรณีคนหนึ่งเข้าระบบไม่ได้ ลาพักร้อน หรือลาออกกะทันหัน

อุปกรณ์และ passkey

พนักงานต้องยืนยันตัวด้วย Face ID / ลายนิ้วมือ / PIN ปลดล็อกหน้าจอ ทุกครั้งที่ลงเวลา การยืนยันนี้ผูกกับ เครื่องนั้น ๆ ไม่ใช่รหัสผ่านที่บอกต่อกันได้ จึงกันการเช็คอินแทนกันได้จริง

ระบบจะผูกอุปกรณ์ให้อัตโนมัติในครั้งแรกที่พนักงานเลื่อนปุ่มเช็คอิน ไม่ต้องตั้งค่าอะไรก่อน

สถานการณ์สิ่งที่ต้องทำ
พนักงานเปลี่ยนมือถือเครื่องใหม่ เข้าไปที่ปุ่ม "อุปกรณ์" แล้ว ถอนสิทธิ์เครื่องเก่า จากนั้นให้เขาเช็คอินจากเครื่องใหม่ ระบบจะผูกให้เอง
มือถือหาย ถอนสิทธิ์เครื่องนั้นทันที คนที่ได้เครื่องไปจะเช็คอินแทนไม่ได้
เครื่องเก่ามาก ไม่มีลายนิ้วมือ/Face ID ให้พนักงาน ตั้ง PIN ล็อกหน้าจอ ก็ใช้แทนกันได้
เครื่องไม่รองรับจริง ๆ ติ๊ก "ยกเว้น passkey" ให้คนนั้น ลดความปลอดภัย เขาจะเช็คอินได้โดยไม่ต้องยืนยันตัว ใช้เท่าที่จำเป็นและทบทวนเป็นระยะ
ทุกครั้งที่มีการพยายามลงเวลา ระบบบันทึกหลักฐานไว้เสมอ ทั้งพิกัด ระยะห่างจากสาขา ความแม่นยำ หมายเลขเครื่อง หมายเลข IP และชนิดอุปกรณ์ ไม่ว่าจะสำเร็จหรือถูกปฏิเสธ ดูได้จากปุ่ม "อุปกรณ์" ในหน้าจัดการพนักงาน

5. ตั้งค่าวันลา

เมนู ตั้งค่าวันลา — สร้างประเภทการลา แล้วกำหนดว่าใครได้สิทธิ์อะไร

ช่องความหมาย
ชื่อประเภทเช่น ลาป่วย ลากิจ ลาพักร้อน
จำนวนวัน/ปีโควตามาตรฐานของประเภทนี้
ต้องยื่นล่วงหน้า (วัน) ระบบจะปฏิเสธถ้ายื่นกระชั้นกว่านี้ ลาป่วยควรใส่ 0 เพราะป่วยล่วงหน้าไม่ได้
ให้สิทธิ์พนักงานทุกคน ติ๊กแล้วทุกคนได้สิทธิ์นี้อัตโนมัติ รวมถึงคนที่เพิ่มเข้ามาทีหลัง
แสดงจำนวนวันลา/ปี ในหน้าพนักงาน ไม่ติ๊ก = พนักงานยังยื่นลาประเภทนี้ได้ แต่จะไม่เห็นตัวเลขโควตาคงเหลือ

กำหนดสิทธิ์รายบุคคล

ถ้าไม่ติ๊ก "ให้สิทธิ์ทุกคน" จะเลือกได้ว่าใครได้บ้าง และ ตั้งโควตาเฉพาะรายได้ด้วย

ตัวอย่างการใช้งานจริง บริษัทให้พักร้อน 6 วัน/ปี แต่คนที่อายุงานเกิน 1 ปีได้ 10 วัน → สร้างประเภท "ลาพักร้อน" โควตา 6 วัน แล้วเข้าไปตั้งโควตาเฉพาะรายเป็น 10 ให้คนที่ครบปี ระบบจะใช้ตัวเลขเฉพาะรายก่อนเสมอ
ระบบยังไม่เลื่อนขั้นโควตาให้อัตโนมัติ เมื่อพนักงานทำงานครบ 1 ปี คุณต้องเข้ามาปรับโควตาเฉพาะรายเอง แนะนำให้ตั้งเตือนในปฏิทินไว้ตรวจปีละครั้ง

6. วันหยุด

เมนู วันหยุด — จัดการทุกอย่างในกล่องปฏิทิน

  • วันหยุดประจำสัปดาห์ — ติ๊กเลือกวันในสัปดาห์ เช่นหยุดเฉพาะอาทิตย์ หรือหยุดเสาร์–อาทิตย์
  • วันหยุดราชการ / วันหยุดพิเศษ — คลิกที่วันในปฏิทิน แล้วใส่ชื่อวันหยุด คลิกซ้ำที่วันเดิมเพื่อแก้ไขหรือลบ

วันหยุดมีผล 3 อย่าง

  1. ในรายงาน วันนั้นจะขึ้นว่า "หยุด" ไม่นับเป็นขาดงาน
  2. การเช็คอินในวันนั้นขึ้นอยู่กับ นโยบาย OT (ดูหัวข้อถัดไป)
  3. ถ้าอนุญาตให้ทำงานวันหยุด เวลาที่ทำจะถูกนับเป็น OT และ ไม่นับว่ามาสาย
ใส่วันหยุดราชการทั้งปีทีเดียวตอนต้นปี จะได้ไม่ต้องมานั่งใส่รายเดือน และรายงานย้อนหลังจะถูกต้องตั้งแต่แรก

7. ตั้งค่า OT (ล่วงเวลา)

เมนู ตั้งค่า OT — นี่คือหน้าที่ควรอ่านให้ละเอียดที่สุด เพราะกฎซ้อนกันหลายชั้น

ระบบนี้เก็บ "ชั่วโมง" อย่างเดียว ไม่คิดเป็นเงิน ตัวคูณ 1.5 เท่า 2 เท่า 3 เท่า ให้ไปคิดที่ระบบเงินเดือนของคุณ สิ่งที่ TapTime ให้คือ จำนวนชั่วโมงที่เชื่อถือได้และตรวจสอบย้อนหลังได้

เลือกโหมดให้ถูก

โหมดการทำงานเหมาะกับ
ปิดระบบ OT ซ่อนทุกอย่างที่เกี่ยวกับ OT ทั้งฝั่งแอดมินและพนักงาน บริษัทที่ไม่มี OT เลย หรือยังไม่พร้อมเปิดใช้
นับอัตโนมัติ อยู่เกินเวลาเลิกงาน = นับให้ทันที ไม่ต้องอนุมัติ ทีมเล็ก ไว้ใจกัน หรือมีหัวหน้าคุมหน้างานอยู่แล้ว
นับก่อน แล้วค่อยอนุมัติ แนะนำ ระบบนับให้ แต่ขึ้นสถานะ "รออนุมัติ" จนคุณกดยืนยัน
ระบบสร้างใบให้เองทุกครั้ง ไม่ต้องรอพนักงานยื่น		 บริษัทส่วนใหญ่ — ได้ทั้งความสะดวกและการควบคุม
ต้องขออนุมัติก่อนทำ ต้องยื่นและอนุมัติก่อนถึงจะนับ ทำเกินใบที่ขอจะถูกตัดตามใบ องค์กรที่ต้องคุมงบ OT เข้มงวด หรือมีข้อกำหนดจากลูกค้า
แอดมินคีย์ให้เท่านั้น พนักงานยื่นไม่ได้ ระบบไม่นับให้เอง คุณบันทึกให้ทีละคน ธุรกิจที่ OT เกิดไม่บ่อยและต้องพิจารณาเป็นราย ๆ
เปลี่ยนโหมดได้ตลอดเวลา และมีผลทันที พนักงานไม่ต้องออกจากระบบแล้วเข้าใหม่ ข้อมูล OT ที่บันทึกไปแล้วไม่เปลี่ยนตาม เพราะแต่ละแถวจำไว้ว่าตอนนั้นใช้กฎอะไร

กฎการนับ 5 ชั้น

ระบบคำนวณตามลำดับนี้เสมอ สลับลำดับไม่ได้ และผลลัพธ์ต่างกันมากถ้าเข้าใจผิด

ชั้นกฎทำอะไร
1ช่วงผ่อนผัน (grace) อยู่ต่อไม่เกินกี่นาทีจึงยังไม่ถือเป็น OT
ต้อง "เกิน" เท่านั้น — ตั้ง 15 แล้วอยู่ต่อ 15 นาทีพอดี ยังไม่นับ
2หักพักระหว่าง OT ทำ OT ยาวเกินเกณฑ์ที่ตั้งไว้ จะหักเวลาพักออก
3ปัดเศษ ปัดลง / ปัดใกล้สุด / ปัดขึ้น ทีละกี่นาที
4ขั้นต่ำต่อครั้ง ไม่ถึงเกณฑ์ ตัดทั้งก้อน ไม่ใช่ตัดแค่เศษ
5เพดาน ต่อวัน → ต่อสัปดาห์ → ต่อเดือน ตามลำดับ
ข้อที่คนเข้าใจผิดบ่อยที่สุด: "ขั้นต่ำตัดทั้งก้อน" ตั้งขั้นต่ำ 30 นาที แล้วพนักงานทำเกิน 25 นาที → ได้ 0 นาที ไม่ใช่ 25 นาที
ถ้าคุณตั้งใจให้ได้ 25 นาที ต้องตั้งขั้นต่ำเป็น 0 แทน

ตัวอย่างการคำนวณจริง

ตั้งค่า: ผ่อนผัน 15 นาที · ขั้นต่ำ 30 นาที · ปัดลงทีละ 30 นาที · เพดาน 4 ชม./วัน กะทำงาน 08:00–17:00

พนักงานเข้า 08:00 ออก 19:20 ───────────────────────────────────────────── 1. อยู่เกินเวลาเลิกงาน 19:20 − 17:00 = 140 นาที (เกินผ่อนผัน 15 → นับ) 2. หักพัก ไม่เข้าเงื่อนไข = 140 นาที 3. ปัดลงทีละ 30 140 → 120 นาที 4. ขั้นต่ำ 30 120 ≥ 30 ผ่าน = 120 นาที 5. เพดาน 240 120 ≤ 240 ไม่ตัด = 120 นาที ───────────────────────────────────────────── ผลลัพธ์: OT 2 ชั่วโมง 0 นาที (20 นาทีที่เหลือถูกปัดทิ้ง)
พนักงานเข้า 08:00 ออก 17:25 ───────────────────────────────────────────── 1. อยู่เกินเวลาเลิกงาน 17:25 − 17:00 = 25 นาที (เกินผ่อนผัน 15 → นับ) 2. หักพัก ไม่เข้าเงื่อนไข = 25 นาที 3. ปัดลงทีละ 30 25 → 0 นาที 4. ขั้นต่ำ 30 0 < 30 = 0 นาที ───────────────────────────────────────────── ผลลัพธ์: ไม่มี OT
ใช้กล่อง "ทดลองคำนวณ" ก่อนกดบันทึกทุกครั้ง อยู่ล่างสุดของหน้าตั้งค่า OT ใส่เวลาเข้า-ออกสมมติแล้วมันจะแสดงผลทีละขั้นให้ดู เป็นสูตรเดียวกับที่เซิร์ฟเวอร์ใช้จริง ไม่ใช่ตัวอย่างประกอบ ลองใส่เคสที่เจอบ่อยในบริษัทดูก่อน

OT ก่อนเข้างาน

ถ้าเปิด "นับ OT ก่อนเวลาเข้างาน" คนที่มาก่อนเวลาแล้วเริ่มทำงานเลยจะได้ OT ด้วย

คิดให้ดีก่อนเปิด พนักงานหลายคนมาเช้าเพราะเลี่ยงรถติด ไม่ได้มาทำงาน ถ้าเปิดข้อนี้โดยตั้งผ่อนผันไว้น้อย บริษัทจะจ่าย OT ให้กับเวลานั่งรอ ถ้าจะเปิด ควรตั้งผ่อนผันก่อนเข้างานไว้อย่างน้อย 30 นาที

เพดาน

กรอกเป็น ชั่วโมง ใส่ 0 = ไม่จำกัด

  • ต่อวัน — ตัดที่เพดานเลย
  • ต่อสัปดาห์ — นับจันทร์ถึงอาทิตย์ เหลือเท่าไรให้เท่านั้น
  • ต่อเดือน — ตัดต่อจากเพดานสัปดาห์อีกชั้น
ยอดสะสมนับทั้งที่อนุมัติแล้วและที่ยังรออนุมัติ ถ้านับแค่ที่อนุมัติแล้ว พนักงานจะทำทะลุเพดานไปได้เรื่อย ๆ ระหว่างที่ใบยังค้างรอคุณกด

การทำงานวันหยุด

ตัวเลือกผลที่เกิดขึ้น
อนุญาตให้เช็คอินในวันหยุดได้ ปิด = พนักงานเช็คอินวันหยุดไม่ได้เลย (พฤติกรรมเดิมก่อนเวอร์ชัน 1.3)
ต้องได้รับอนุมัติก่อนจึงเช็คอินวันหยุดได้ เปิด = พนักงานต้องยื่น "ใบขอทำงานวันหยุด" และคุณต้องอนุมัติก่อน เขาถึงจะเช็คอินได้
วันหยุดนับเป็น OT ทั้งวัน เปิด = ทุกนาทีที่อยู่คือ OT
ปิด = นับเฉพาะส่วนที่เกินเวลาเลิกงาน เหมือนวันทำงานปกติ
ใบขอทำงานวันหยุดยื่นได้ทุกโหมด (ยกเว้นโหมดปิดระบบ) ต่างจากใบ OT ปกติที่ยื่นได้เฉพาะโหมดที่เปิดให้ยื่น ทำแบบนี้เพื่อไม่ให้เกิดทางตัน — ไม่งั้นถ้าคุณเลือกโหมด "นับอัตโนมัติ" แต่บังคับว่าวันหยุดต้องขออนุมัติ พนักงานจะไม่มีทางสร้างใบได้เลย

เมื่อพนักงานเช็คอินไม่ได้เพราะยังไม่มีใบอนุมัติ หน้าจอเขาจะขึ้นปุ่มลัดให้ยื่นใบทันที คุณจะได้รับแจ้งเตือน กดอนุมัติ แล้วเขาเช็คอินได้เลย

ตัวอย่างการตั้งค่าตามประเภทธุรกิจ

ธุรกิจโหมดกฎที่แนะนำ
ร้านอาหาร / ค้าปลีกนับก่อน แล้วค่อยอนุมัติ ผ่อนผัน 15 · ขั้นต่ำ 30 · ปัดลง 30 · เพดาน 4 ชม./วัน · วันหยุดนับทั้งวัน
ออฟฟิศต้องขออนุมัติก่อนทำ ผ่อนผัน 30 · ขั้นต่ำ 60 · ปัดลง 30 · เพดาน 3 ชม./วัน และ 36 ชม./เดือน
โรงงาน / คลังสินค้านับอัตโนมัติ ผ่อนผัน 10 · ขั้นต่ำ 30 · ปัดลง 30 · หักพัก 30 นาทีเมื่อ OT ถึง 4 ชม. · เพดาน 4 ชม./วัน
ทีมเล็ก / OT นาน ๆ ครั้งแอดมินคีย์ให้เท่านั้น ไม่ต้องตั้งกฎมาก เพราะคุณกำหนดจำนวนเองทุกครั้ง
ตัวเลขเหล่านี้เป็นจุดตั้งต้น ไม่ใช่คำแนะนำทางกฎหมาย กฎหมายแรงงานกำหนดเพดานชั่วโมงทำงานล่วงเวลาและอัตราค่าจ้างไว้ โปรดตรวจสอบกับฝ่ายบุคคลหรือที่ปรึกษากฎหมายของคุณก่อนใช้จริง

8. งานประจำวัน

เช็คชื่อ เข้า-ออก

เมนู เช็คชื่อ เข้า - ออก แสดงสถานะของทุกคนในวันที่เลือก กรองตามสาขาและสถานะได้

ปุ่มใช้เมื่อไร
เช็คชื่อแทน (เข้า) พนักงานมาทำงานจริงแต่ลืมกด หรือมือถือแบตหมด
เช็คชื่อแทน (ออก) ลืมเช็คเอาท์ก่อนกลับ
แก้เวลาออก เวลาที่บันทึกไว้ผิด ต้องแก้ให้ตรงความจริง
คีย์ OT ขึ้นเฉพาะโหมด "แอดมินคีย์ให้เท่านั้น" ใช้บันทึก OT ให้ทีละคน

คอลัมน์ OT แสดงเป็น ดิบ / นับได้ พร้อมสถานะ

  • ดิบ = จำนวนนาทีที่อยู่เกินจริง ก่อนหักพัก ปัดเศษ และตัดเพดาน
  • นับได้ = ตัวเลขที่ใช้จริง
ทำไมต้องเก็บค่าดิบไว้ด้วย เวลาพนักงานมาถามว่า "ทำไมอยู่ต่อ 2 ชั่วโมงครึ่ง แต่ได้ OT แค่ 2 ชั่วโมง" คุณจะเปิดให้ดูได้ทันทีว่าเลข 150 กลายเป็น 120 เพราะกฎปัดเศษข้อไหน
เวลาแก้แล้ว OT คำนวณใหม่ให้เองอัตโนมัติ ไม่ว่าจะแก้จากปุ่มนี้หรือจากการอนุมัติคำขอแก้เวลา และถ้าแก้จนไม่เหลือ OT ใบที่ระบบสร้างค้างไว้จะถูกยกเลิกให้เอง

อนุมัติการลา

เมนู ลา - ขาดงาน — กดแท็บ "รออนุมัติ" แล้วกด ✓ อนุมัติ หรือ ✕ ปฏิเสธ พนักงานจะได้รับแจ้งเตือนทันที

ระบบกันยื่นลาซ้อนวันให้แล้ว ถ้าพนักงานยื่นลาทับกับใบที่ยัง "รออนุมัติ" หรือ "อนุมัติแล้ว" ระบบจะปฏิเสธพร้อมบอกว่าทับกับใบไหน

คำขอแก้เวลา

เมนู คำขอแก้เวลา — ใช้ตอนพนักงานลืมเช็คเอาท์ หรือเวลาผิด พออนุมัติ ระบบจะเขียนเวลาใหม่ลงในรายการลงเวลาและคำนวณชั่วโมงทำงานกับ OT ใหม่ให้ทันที

ตรวจก่อนอนุมัติเสมอ เพราะการอนุมัติจะเปลี่ยนตัวเลขชั่วโมงทำงานจริง ดูว่าเวลาที่ขอสมเหตุสมผลกับงานวันนั้นไหม และเทียบกับเวลาเดิมที่ระบบแสดงให้ในใบคำขอ

อนุมัติ OT

เมนู อนุมัติ OT — เมนูนี้จะซ่อนถ้าตั้งโหมดเป็น "ปิดระบบ OT"

  1. เลือกแท็บ รออนุมัติ แล้วกรองตามช่วงวัน สาขา หรือชื่อได้
  2. ดูคอลัมน์ ยื่นขอ เทียบกับเวลาจริงที่บันทึกไว้
  3. ถ้าเห็นด้วยตามนั้น กด ✓ อนุมัติ ได้เลย
  4. ถ้าอยากให้น้อยกว่าที่ขอ แก้ตัวเลขในช่อง "อนุมัติ" ก่อนกด — ใส่เกินที่ยื่นขอไม่ได้
  5. ถ้ามีหลายรายการที่ตรวจแล้วโอเคทั้งหมด ติ๊กเลือกแล้วกด อนุมัติที่เลือก
ที่มาของใบหมายความว่า
ระบบบันทึกให้ พนักงานเช็คเอาท์เกินเวลา ระบบสร้างใบให้อัตโนมัติ (โหมด "นับก่อน แล้วค่อยอนุมัติ")
พนักงานยื่นเอง เขากดยื่นจากแอป มักมีเหตุผลระบุมาด้วย
แอดมินคีย์ให้ คุณหรือแอดมินคนอื่นบันทึกให้ อนุมัติแล้วตั้งแต่แรก
ใบ "ขอทำงานวันหยุด" ไม่ใช่จำนวนชั่วโมง OT มันเป็นเหมือนใบผ่านทางที่ปลดล็อกให้พนักงานเช็คอินในวันหยุดได้เท่านั้น ชั่วโมงจริงจะถูกคำนวณตอนเขาเช็คเอาท์ จากเวลาเข้า-ออกที่เกิดขึ้นจริง

9. รายงาน

รายงานใช้ทำอะไร
ภาพรวม หน้าแรก ดูยอดวันนี้แบบเร็ว ๆ ว่าใครมาแล้ว ใครยังไม่มา ใครสาย
รายงานรายวัน สถานะของทุกคนในวันเดียว รวมคนที่ลาและคนที่ขาด เหมาะกับการเช็ครายวันตอนเช้า
รายงานประจำเดือน ตารางพนักงาน × วัน เห็นภาพทั้งเดือนในหน้าเดียว + ยอดรวม OT ต่อคน
ดาวน์โหลดเป็น Excel ได้
รายงาน OT ตัวที่ส่งต่อระบบเงินเดือน — สรุปชั่วโมงรายคน แยกวันทำงาน / วันหยุดสัปดาห์ / วันหยุดราชการ พร้อมปุ่มคัดลอกตารางไปวางใน Excel ได้ทันที
ทุกรายงานนับเฉพาะ OT ที่ "อนุมัติแล้ว" เท่านั้น ส่วนที่ยังรออนุมัติแสดงแยกคนละคอลัมน์ และ ไม่ถูกรวมในยอดรวม ก่อนปิดงวดเงินเดือนทุกครั้ง ให้เข้าเมนู "อนุมัติ OT" เคลียร์ใบที่ค้างให้หมดก่อน ไม่งั้นชั่วโมงเหล่านั้นจะไม่ถูกจ่าย

ชั่วโมงทำงานกับ OT ไม่นับซ้ำกัน

ตั้งแต่เวอร์ชัน 1.3 ระบบยึดสมการนี้เสมอ

ชั่วโมงงานปกติ + ชั่วโมง OT = เวลาที่อยู่ที่ทำงานจริง − เวลาพัก

เช่นคนที่อยู่ 08:00–19:20 พักเที่ยง 1 ชั่วโมง ได้ OT 2 ชั่วโมง รายงานจะแสดงชั่วโมงงานปกติ 8.33 และ OT 2.00 รวมเป็น 10.33 ชั่วโมงพอดี

ถ้าคุณเคยใช้ไฟล์รายงานจากเวอร์ชันก่อนไปคิดเงิน ให้ตรวจซ้ำ เวอร์ชันเก่านับชั่วโมง OT ซ้ำอยู่ในช่องชั่วโมงทำงานด้วย ทำให้ตัวเลขรวมสูงเกินจริง

10. ความปลอดภัย

ระบบป้องกันอะไรวิธีที่ใช้
เช็คอินแทนกัน ต้องยืนยันด้วย Face ID / ลายนิ้วมือ / PIN ของเครื่องนั้นทุกครั้ง และตัวตนถูกกำหนดจากบัญชีที่ล็อกอินอยู่เท่านั้น แก้ในหน้าเว็บไม่ได้
เช็คอินจากนอกที่ทำงาน ตรวจระยะห่างจากพิกัดสาขา และปฏิเสธพิกัดที่คลาดเคลื่อนเกิน 200 เมตร
ถ้าส่งพิกัดมาไม่ครบหรือไม่ถูกต้อง จะถูกปฏิเสธเสมอ
การแอบอ้างสิทธิ์แอดมิน ตรวจสิทธิ์จากฐานข้อมูลสด ๆ ทุกครั้ง ไม่ได้เชื่อค่าที่เก็บไว้ในเบราว์เซอร์
การปฏิเสธความรับผิด บันทึกหลักฐานทุกครั้งที่พยายามลงเวลา ทั้งพิกัด ระยะ IP และเครื่อง
สิ่งที่ระบบยังกันไม่ได้ ต้องอาศัยการจัดการ
  • พนักงานยื่นมือถือให้เพื่อนสแกนนิ้วให้ — ต้องอาศัยกล้องวงจรปิดหรือหัวหน้างาน
  • แอปปลอมตำแหน่ง GPS บนเครื่องที่ปลดล็อกระบบ (root/jailbreak) — ระบบตรวจความแม่นยำช่วยได้บางส่วน แต่ไม่ 100%
  • คนที่ถูกติ๊ก "ยกเว้น passkey" ไว้ — ทบทวนรายชื่อนี้เป็นระยะ

สิ่งที่คุณควรทำเป็นประจำ

  • ตรวจรายชื่อแอดมินทุกไตรมาส ถอนสิทธิ์คนที่ย้ายแผนกหรือลาออก
  • ตรวจรายชื่อคนที่ถูกยกเว้น passkey ว่ายังจำเป็นอยู่ไหม
  • ถอนสิทธิ์อุปกรณ์ทันทีเมื่อมีคนแจ้งว่ามือถือหาย
  • เปลี่ยนสถานะเป็น "ลาออก" ทันทีในวันสุดท้ายที่ทำงาน

11. ปัญหาที่พบบ่อย

พนักงานบอกว่าเช็คอินไม่ได้ ขึ้นว่า "อยู่นอกพื้นที่"

ข้อความจะบอกด้วยว่าเขาอยู่ห่างกี่เมตรและอนุญาตกี่เมตร ให้ดูตัวเลขนั้นก่อน

  • ห่างไม่มาก (เช่น 60 เมตร จากรัศมี 50) → รัศมีคุณแคบเกินไป ขยายเป็น 80–100 เมตร
  • ห่างมาก (หลายร้อยเมตรขึ้นไป) → พิกัดสาขาอาจปักผิด ลองเปิดแผนที่ตรวจดูว่าหมุดอยู่ตรงที่ทำงานจริงไหม
  • เฉพาะบางคนบางเครื่อง → ให้เขาออกไปยืนกลางแจ้งแล้วลองใหม่ GPS ในอาคารมักเพี้ยน
พนักงานไม่ได้รับอีเมลเชิญ
  1. ให้เขาเช็คโฟลเดอร์ สแปม / จดหมายขยะ ก่อน
  2. ตรวจว่าอีเมลในระบบสะกดถูก
  3. กดปุ่ม ส่งอีเมลเชิญใหม่ ในหน้าจัดการพนักงาน
  4. ถ้ายังไม่ได้ ใช้ ตั้งรหัสผ่านให้ แล้วบอกรหัสเขาด้วยวาจา ให้เขาเปลี่ยนเองภายหลัง
พนักงานทำงานข้ามคืน ระบบคำนวณให้ไม่ได้

ถูกต้อง ระบบเวอร์ชันนี้ ตั้งใจไม่รองรับกะข้ามเที่ยงคืน เพราะโครงสร้างข้อมูลเก็บ 1 คน 1 แถวต่อวัน ถ้าเดาว่าข้ามวันจะทำให้ข้อมูลผิดโดยไม่มีใครรู้

ถ้าเวลาออกน้อยกว่าหรือเท่ากับเวลาเข้า ระบบจะให้ OT เป็น 0 และบันทึกเหตุผลไว้

วิธีจัดการชั่วคราว: ให้พนักงานเช็คเอาท์ก่อนเที่ยงคืน แล้วเช็คอินใหม่หลังเที่ยงคืน หรือให้ยื่นคำขอแก้เวลาแล้วคุณบันทึกชั่วโมงให้ด้วยปุ่ม "คีย์ OT"

ตัวเลข OT ไม่ตรงกับที่พนักงานคิดไว้

เปิดหน้า ตั้งค่า OT แล้วใช้กล่อง "ทดลองคำนวณ" ใส่เวลาเข้า-ออกของเขา ระบบจะแสดงให้ดูทีละขั้นว่าเลขหายไปที่กฎข้อไหน

สาเหตุที่พบบ่อยเรียงตามความถี่

  1. ปัดเศษ — ทำ 2 ชั่วโมง 20 นาที แต่ตั้งปัดลงทีละ 30 → ได้ 2 ชั่วโมง
  2. ขั้นต่ำ — ทำ 25 นาที แต่ขั้นต่ำ 30 → ได้ 0 ไม่ใช่ 25
  3. ช่วงผ่อนผัน — อยู่ต่อ 15 นาทีพอดีโดยตั้งผ่อนผัน 15 → ยังไม่นับ ต้องเกิน
  4. เพดาน — ชนเพดานรายวันหรือรายสัปดาห์ไปแล้ว
เปลี่ยนกฎ OT แล้ว ข้อมูลเก่าจะเปลี่ยนตามไหม

ไม่เปลี่ยน ทุกแถวลงเวลาจำไว้ว่าตอนนั้นคำนวณด้วยกฎชุดไหน และการบันทึกนโยบายใหม่จะสร้างชุดกฎใหม่เสมอ ไม่ทับของเก่า

ถ้าอยากให้ข้อมูลวันใดวันหนึ่งคำนวณใหม่ด้วยกฎปัจจุบัน ให้เข้าเมนูเช็คชื่อเข้า-ออก แล้วกด แก้เวลาออก โดยใส่เวลาเดิม ระบบจะคำนวณใหม่ทั้งหมด

อยากปิดระบบ OT ชั่วคราว

ไปที่ ตั้งค่า OT เลือกโหมด "ปิดระบบ OT" แล้วบันทึก เมนูที่เกี่ยวกับ OT จะหายไปทั้งฝั่งคุณและฝั่งพนักงานทันที

ข้อมูล OT ที่บันทึกไว้แล้ว ไม่หาย เปิดกลับมาเมื่อไรก็เห็นเหมือนเดิม

พนักงานลาออกแล้ว ควรทำอย่างไร

เข้า จัดการพนักงาน → แก้ไข → เปลี่ยนสถานะเป็น "ลาออก"

เขาจะเข้าระบบไม่ได้และหายจากรายงานทันที แต่ประวัติการทำงานยังอยู่ครบ อย่าใช้ปุ่มลบ เพราะจะลบประวัติทั้งหมดไปด้วย

รายงานเดือนแสดงยอด OT ไม่ตรงกับรายงาน OT

ทั้งสองหน้าใช้ข้อมูลชุดเดียวกันและต้องได้เลขเท่ากัน ถ้าไม่ตรงให้ตรวจ

  • ช่วงวันที่ ตรงกันหรือเปล่า — รายงานเดือนใช้ทั้งเดือน แต่รายงาน OT ตั้งช่วงเองได้
  • ตัวกรองสาขา ในรายงาน OT ถูกตั้งไว้อยู่หรือเปล่า
  • คุณกำลังดู คอลัมน์รออนุมัติ ปนกับยอดรวมอยู่หรือเปล่า

ภาคผนวก — สูตรคำนวณทั้งหมด

มาสาย

นาทีที่สาย = เวลาเข้างานจริง − เวลาเริ่มงานตามกะ (ติดลบให้เป็น 0) สถานะ = สายเกินเกณฑ์ที่ตั้งไว้ ? "มาสาย" : "ปกติ" ทำงานวันหยุดไม่นับมาสาย เพราะไม่มีเวลาเข้างานให้สายตั้งแต่แรก

ชั่วโมงทำงานปกติ

เวลาที่อยู่จริง = เวลาออก − เวลาเข้า หักเวลาพัก = ถ้าเวลาที่อยู่จริง ≥ เกณฑ์หักพัก → ลบชั่วโมงพักออก ชั่วโมงงานปกติ = (เวลาที่อยู่จริง − เวลาพัก) − ชั่วโมง OT ที่นับได้ หัก OT ออกเพื่อไม่ให้นับซ้ำตอนส่งต่อระบบเงินเดือน

OT — ลำดับ 6 ขั้น

0. โหมดปิด → 0 0.5 เวลาออก ≤ เวลาเข้า → 0 (กะข้ามคืน ไม่รองรับ) 1. เวลาดิบ วันหยุด + นับทั้งวัน → เวลาออก − เวลาเข้า วันทำงาน หลังเลิกงาน → เวลาออก − เวลาเลิกงาน (เฉพาะเมื่อ "เกิน" ผ่อนผัน) วันทำงาน ก่อนเข้างาน → เวลาเริ่มงาน − เวลาเข้า (ถ้าเปิดใช้) 2. หักพัก ถ้า OT ≥ เกณฑ์ → ลบนาทีพักออก 3. ปัดเศษ ปัดลง / ปัดใกล้สุด / ปัดขึ้น 4. ขั้นต่ำ ไม่ถึงเกณฑ์ → 0 ทั้งก้อน 5. เพดาน ต่อวัน → ต่อสัปดาห์ (จ–อา) → ต่อเดือน ยอดสะสมนับทั้งอนุมัติแล้วและรออนุมัติ 6. สถานะตามโหมด นับอัตโนมัติ → นับแล้ว นับก่อนค่อยอนุมัติ → รออนุมัติ (สร้างใบให้เอง) ต้องขอก่อนทำ → นับได้ไม่เกินที่อนุมัติไว้ แอดมินคีย์ให้เท่านั้น → ไม่นับ

โควตาวันลาคงเหลือ

คงเหลือ = โควตาของประเภทนั้น − วันที่ลาไปแล้วในปีนี้ (นับเฉพาะใบที่อนุมัติแล้ว) ถ้ามีโควตาเฉพาะราย ระบบใช้ตัวเลขเฉพาะรายก่อนเสมอ
